## 1. 신규 연출 및 UX 기능 구현 (New Features)

### 배리어 블록 맨해튼 거리 기반 방사형 파괴 시스템

- **기획 의도:** 스테이지 마지막의 7줄 배리어 층을 파괴할 때, 타격 지점을 중심으로 블록이 순차적으로 제거되며 지층이 열리는 연출을 구현했습니다.

- **구현 핵심:** 상하좌우 격자 거리 차이를 계산하는 **맨해튼 거리(Manhattan Distance)** 공식을 적용했습니다.
$$\text{Dist} = |\text{BlockX} - \text{CenterX}| + |\text{BlockY} - \text{CenterY}|$$
거리가 1칸 멀어질 때마다 `Dist * 0.05f`초의 지연을 부여해 `ForcePop()`이 순차적으로 실행되도록 설계했습니다. 배리어가 아닌 상단의 일반 블록은 연출 없이 즉시 풀로 회수되도록 분리했습니다.

### 스테이지 전환 시 플레이어 체공(Time-Stop) 및 끼임 방지

- **문제 상황:** 배리어가 방사형으로 파괴되는 지연 시간 동안 플레이어가 중력 가속도를 받아 깊게 추락하면서, 새 맵 스폰 시 블록 사이에 끼는 문제가 발생했습니다.

- **해결 방법:** 배리어 타격 즉시 플레이어 캐릭터의 `GravityScale`을 `0.0f`로 설정하고 `Velocity`를 초기화했습니다. 새 맵 생성이 끝난 뒤 중력을 `1.0f`로 복구하고, 끼임 방지를 위해 Z축 오프셋을 상단으로 보정했습니다.

### 무한 하강을 위한 엔진 KillZ 시스템 조정

- **내용:** Unreal Engine 기본 설정에서는 특정 지하 깊이에 도달하면 `KillZ`에 의해 액터가 제거됩니다. 무한 하강 구조와 충돌하지 않도록 `L_InGame` 맵의 **World Settings**에서 `Kill Z` 값을 조정하고 바운드 체크를 비활성화했습니다.

### 💎 UI 나인 슬라이스(9-Slice) 및 배경화면 세팅

- **UI 테두리 고정:** 텍스트를 감싸는 테두리 이미지가 가로로 늘어날 때 모서리가 찌그러지지 않도록 브러시 모드를 `Draw As: Box`로 변경 후 Margin 비율을 `0.25`로 고정.

- **카메라 종속 배경:** 맵이 무한히 깊어지므로 배경을 월드에 배치하지 않고 `BP_MainCamera`의 자식 컴포넌트로 붙여 카메라 추적 시 자동으로 따라오도록 최적화. 렌더링 환경광 간섭을 막기 위해 머티리얼을 `MaskedUnlitSpriteMaterial`로 변경.

- **카메라 노출 고정 (Exposure Lock):** 조명이 없는 2D 환경에서 자동 노출이 화면을 과보정하는 현상을 차단하기 위해 카메라 디테일에서 `Min EV100`과 `Max EV100`을 동일한 수치(예: `1.0`)로 강제 묶어 순정 2D 색감 확보.

### 💎 산소 실시간 텍스트 % 연동

- **내용:** 게이지 바 연출에 더해 텍스트로도 직관적인 남은 산소량을 표기.

- **구현:** `InGameHUDWidget`에 `UTextBlock* Txt_Oxygen`을 연동. 매 프레임 `FMath::RoundToInt(CurrentOxygen)`로 정수 반올림 후 `FString::Printf(TEXT("%d %%"), DisplayOxygen)` 포맷을 적용하여 소수점 울렁거림 없이 깔끔한 수치 출력 완료.
